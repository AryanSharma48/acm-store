# ACM Store

ACM Store is an online store for merchandise of ACM MUJ.

## Installation

Follow these steps to install the project:

```bash
npm install
```

## Usage

You can run the following scripts:

- `npm start`

## Dependencies

This project uses the following dependencies:

- @supabase/supabase-js
- lucide-react
- next
- razorpay
- react
- react-dom
